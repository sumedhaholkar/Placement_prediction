# Student Placement Prediction

## About the Project

This project focuses on analyzing student academic,
skill-related and extracurricular data to understand
factors associated with student placement outcomes.

Exploratory Data Analysis (EDA) is the main focus of
this project, followed by machine learning classification.

## Dataset

The dataset contains information about students including:

- CGPA
- Internships
- Projects
- Aptitude Test Score
- Soft Skills Rating
- SSC Marks
- HSC Marks
- Placement Training
- Extracurricular Activities
- Placement Status

## Exploratory Data Analysis

The project includes:

- Data understanding
- Missing-value analysis
- Duplicate detection
- Univariate analysis
- Bivariate analysis
- Distribution analysis
- Correlation analysis
- Placement-related analysis

## Machine Learning

The following classification models were compared:

- Logistic Regression
- Decision Tree
- Random Forest
- KNN
- SVM

### Model Comparison

| Model | Mean F1 Score |
|---|---:|
| Logistic Regression | 0.7956 |
| SVM | 0.7947 |
| Random Forest | 0.7825 |
| KNN | 0.7703 |
| Decision Tree | 0.7038 |

Logistic Regression currently gives the best
cross-validation F1 score of 0.7956.
